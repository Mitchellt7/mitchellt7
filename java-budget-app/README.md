# Tidy Budget Planner (Java Desktop App)

A clean Windows-friendly Java Swing budgeting app with dedicated areas for:

- **Actual income + actual expenses**
- **Expected income + expected expenses**
- Side-by-side comparison layout
- Add/remove row boxes for category + amount entry
- Automatic totals and balance cards

## Requirements

- Java 17 or newer

## Run

From repository root:

```bash
javac java-budget-app/src/BudgetApp.java
java -cp java-budget-app/src BudgetApp
```

On Windows, this opens a desktop window with a tidy UI and editable data boxes.
