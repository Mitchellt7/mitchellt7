# Budget Buddy

Budget Buddy is a lightweight responsive budgeting app that runs in any modern browser.

## Features

- Add income and expense transactions
- Track total income, expenses, and balance
- View spending grouped by category
- Delete transactions
- Local persistence via browser localStorage
- Responsive layout with mobile and tablet/desktop breakpoints

## Run locally

```bash
npm install
npm run start
```

Then open: `http://localhost:4173`.

## Notes

- No npm dependencies are required.
- This avoids restricted package registry issues in locked-down environments.

## Java Windows desktop version

A desktop Java Swing version is included at `java-budget-app/` with a polished UI for actual and expected income/expenses.

See: `java-budget-app/README.md` for run instructions.
